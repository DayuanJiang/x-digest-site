Musk 检查回收的42号飞船，称助推器问题不影响进度后续

14 条帖子，合计浏览 1581 万次

之前的报道：11月15日早间“Starship 飞船首次被发射塔接住”

42号飞船被接住后，Musk 在发射塔上检查了飞船，并发了现场拍的视频。他还说明了22号助推器没飞回来的原因和修正办法，并表示这不影响 Starship 的整体进度。

回收检查
Musk 日本时间15日7点36分发帖说正在检查42号飞船，9点33分又发了几段在发射塔上用手机拍的视频，其中一段是从下方仰拍飞船，属于回收后的检查。 X 上 Musk 帖子、Deccan Herald
隔热罩
26颗 Starlink V3 中有3颗带摄像头，拍了飞船的隔热罩。SpaceX 说照片显示隔热罩状态良好，可以再入，所以控制团队夜里放弃了备用的海上溅落方案；返回当天早上，SpaceX 在 X 上宣布“发射台和塔架系统可以进行回收”。 Teslarati
助推器
SpaceX 的 Dan Huot 说，助推器起初获准回收，但在后段滑行时自己检测到制导、导航与控制（GNC）问题，于是中止回收，在墨西哥湾上空悬停后触发飞行终止系统落水。Musk 说是发动机性能略低导致推进剂不够，修正办法是在 Raptor V3.2 上提高发动机的一致性，并修改飞行软件，让发动机提前约1秒关机，留足返回用的燃料。 Teslarati
进度表态
Musk 说，这次损失助推器不会改变 Starship 实现大批量、完全重复使用飞行的时间表。他此前说过，预计2027年上半年 Starship 能做到每周发射一次。 Teslarati
此前
42号飞船绕地球14圈后，日本时间15日6点20分前后被发射塔机械臂接住，是第一次回收 Starship 上面级；22号助推器没能飞回发射塔。 Teslarati、Space.com

Claude Code 试验性加入 Code Mode

2 条帖子，合计浏览 3.9 万次

Claude Code 官方文档新增了 Code Mode 页面。这是一个试验性功能，默认关闭，开启后 Claude 会写一段 JavaScript，一步完成多个工具调用。

工作方式
不开 Code Mode 时，Claude 逐个调用 Bash、Read、Edit 等工具，每看完一个结果再决定下一步；开启后，Claude 写一段 JavaScript，由 Claude Code 在会话中执行，一段代码可以并行跑命令、把上一步结果用到下一步，只把需要的部分输出交回给 Claude。对话里显示的是工具调用，按 Ctrl+O 可以在记录查看器里看到代码。 Claude Code 官方文档
适用场景
官方建议在需要很多相关工具调用的任务上试用，例如要在很多文件里重复改同一处、搜索结果需要先过滤再给 Claude 看、几条互不相关的命令可以同时跑。 Claude Code 官方文档
使用条件
需要 Claude Code v2.1.323 或更新版本（有用户说在2.1.325版里试用），模型限 Opus 5.5、Sonnet 5.5、Haiku 5.5 和 Fable 5.2；要用 Claude 订阅或 Console 账号，经网关、Amazon Bedrock、Microsoft Foundry 等渠道不能用，只支持终端里的交互式会话和原生安装版，-p 模式、Agent SDK、VS Code 面板和桌面应用都不行。 Claude Code 官方文档、X 用户
开启方法
把环境变量 CLAUDE_CODE_EXPERIMENTAL_CODE_MODE 设为1，第一次启动时确认开启。项目里的设置文件不能打开这个功能；组织可以在托管设置里把它设为0，禁止所有成员使用。 Claude Code 官方文档
限制
代码运行时如果要等结果，最长10分钟就会停止；放到后台跑最长2小时，需要 auto 或 bypassPermissions 模式。会话只能在终端里、开着 Code Mode 时恢复，不能用 Remote Control、Claude in Chrome 和 computer use；官方说明这个功能以后可能改动或移除。 Claude Code 官方文档
权限检查
代码里的每个工具调用都照常经过 deny、ask 权限规则和 PreToolUse hook；auto 模式下，分类器审查的是整段代码，看不到运行时才算出的值。 Claude Code 官方文档

KaiHEN 附带 FTP 工具，23.5.0 SDK 被完整导出后续

5 条帖子，合计浏览 2.2 万次

之前的报道：11月15日早间“kurumuz 正式发布 KaiHEN，RetroArch 已移植”

gamegaz 介绍了 KaiHEN 的启动操作和附带工具，最新版本是20261114d。另外，ONE Jailbreak 说23.5.0版 SDK 已被完整导出。

启动操作
安装 KaiHEN 后先退出游戏，再按住 R 键启动一款 Switch 2 游戏，重复两次就会进入 KaiHEN 自带的自制软件菜单 hbmenu。gamegaz 认为这款游戏需要是 Switch 2 专用游戏，并说明自己没有实机测试。 gamegaz
附带工具
KaiHEN 附带 OunceShell，这是老牌文件管理工具 Vitashell 的移植版，带 FTP 服务器功能，可以通过无线网络把自制软件传到主机上。开发套件以 ounce-devkit 名义在 GitHub 公开，KaiHEN 当前最新版本是20261114d。 gamegaz、kurumuz（Eren Doğan）X 帖子
能力范围
KaiHEN 对应23.0.1及以前的系统版本。gamegaz 说，Switch 2 目前拿不到内核级权限，只能访问文件系统，KaiHEN 就是在这个范围里启动自制软件，本质上是 HEN（Homebrew Enabler），和 Atmosphere 那样的自定义固件有区别。 gamegaz
SDK 导出
ONE Jailbreak 发帖说，23.5.0版 SDK 被100%导出，附有十六进制和反汇编内容；这套 SDK 是打包在游戏本身里的（卡带上的 Switch 1 程序），和主机系统无关。 ONE Jailbreak

联邦法官暂时阻止 Trump 关闭华盛顿高尔夫球场

3 条帖子，合计浏览 40.1 万次

美国联邦法官 Ana Reyes 在美国时间14日晚（日本时间15日上午）发出临时限制令，禁止 Trump 政府关闭华盛顿的 East Potomac 公园和高尔夫球场。原计划是从15日起封闭15个月，改造成锦标赛级球场。

裁定内容
这份30页的裁定禁止政府在原有开放时段关闭 East Potomac 公园和球场，但不要求政府主动管理，政府仍可按现有的初步禁令发通知后维修；命令有效到美国时间11月28日或法院另有命令时为止，AP 称这等于让一切工程暂停两周。 AP、BBC
裁定理由
Trump 10月26日发帖说会按计划在11月15日关闭球场进行翻修，Reyes 认为这些帖子说明改造计划已经定案、国家公园管理局会关闭公园来执行，这对政府不利。CNN 报道，法官认为改造计划可能违反环境法，也不符合行政程序方面的要求。 AP、CNN
起诉方
起诉方是 DC Preservation League 和两名当地高尔夫球手，今年2月提起诉讼，认为改造会改变这座公共球场的性质，让人打不起球；代理他们的 Democracy Forward 律师 Catherine Carroll 欢迎这项裁定。 AP
政府说法
司法部律师 Adam Gustafson 在美国时间13日的庭审上说，关闭是出于安全考虑，而且政府和现在的运营方 National Links Trust 的租约在15日到期；Reyes 指出几个月来关闭的讨论都没提过安全问题。司法部声明说，命令并不妨碍继续规划世界级球场。Trump 在裁定前发帖批评 Reyes，并说华盛顿地区居民打球可以享受五折。 AP、CBS
背景
这座球场已有106年历史，在杰斐逊纪念堂附近，离白宫约3公里。10月政府在假期周末砍掉大批树木后，Reyes 开始发出停工命令；司法部曾要求她回避这个案子，她没有回避，还计划指派前华盛顿联邦检察官 Jessie Liu 调查官员是否误导了法庭。 AP、Khaleej Times
