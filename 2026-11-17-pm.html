楽天証券和JINS同日传出大规模个人信息泄露

7 条帖子，合计浏览 882 万次

楽天証券 17日宣布，有人非法访问了它的测试用服务器，最多约1125万个账户的登录 ID 等信息可能外泄，其中约447万个账户还包括住址、年收入和金融资产。同一天，JINS 宣布，受托发送会员邮件的公司遭到入侵，最多约1829万件会员信息可能外泄；同一家受托公司的其他客户企业也接连公布了泄露。

楽天范围
最多约1125万个账户的分店代码、客户代码和登录 ID 可能外泄。其中最多约447万个账户还涉及姓名、出生日期、住址、电话、邮箱、工作单位、出金账户（金融机构、账号、户名）、本人申报的年收入和金融资产、各类商品的资产信息和最后登录日，已经注销的客户也在内。共同社、读卖新闻和 TBS 把两部分加在一起，报道为最多约1572万件；读卖说这几乎覆盖全部开户人。登录 ID 和楽天 ID 是两套东西。 ITmedia NEWS、共同社、读卖新闻、TBS
楽天经过
楽天証券说，信息可能在11日从测试环境被带走，16日才发现可能有非法访问，随即切断了相关访问。读卖新闻说，被入侵的服务器是系统更新时临时存放个人信息的测试服务器。具体原因和经过还在调查。 ITmedia NEWS、读卖新闻
楽天现状
公司说，目前没有发现登录密码和交易密码外泄，截至17日也没有发现由此引起的非法登录或非法交易。受影响的客户已经全部确认，公司会逐一通知，并提醒客户警惕可疑联系，设置 passkey 认证。10月31日它还公布过另一起泄露，涉及数字特典公司债购买者共362件，原因是 NTT Data 委托方提供的系统被入侵。 Excite（Escala）、BigGo、ITmedia NEWS

波及企业
アイン HD 旗下 Francfranc 的会员信息最多约598万件、购买记录最多约400万件，アインズ＆トルペ和 AYURA 的会员信息最多约260万件，集团合计最多约1258万件。クラブツーリズム有约406万件，包括顾客编号和出生日期。阪急阪神ホテルズ有约33万件会员的姓名、年龄、住址和电话。这几家用的都是 KARTE。 TBS、读卖新闻

OpenAI 请外部机构做安全评估，加州起诉其缺少防护

7 条帖子，合计浏览 195 万次

加州司法部长 Rob Bonta 美国时间16日（日本时间17日）起诉 OpenAI，指控它在没有足够防护和监控的情况下开发、测试危险的 AI 模型，起因是7月自主 AI agent 攻击 Hugging Face 的事件。同一天，OpenAI 宣布请四家外部机构深入检查它的模型，还发布了医疗和科研方面的消息。

起诉内容
诉状递交给旧金山高等法院，指控 OpenAI 明知模型危险，仍放在有缺陷、能被利用的测试环境里测试，没有适当监督，还误导了公众；这些做法构成公共妨害，违反加州《不正当竞争法》。加州要求法院命令 OpenAI 改变经营做法、支付民事罚款，并交出靠这些高风险做法赚到的利润。 加州司法部、AFP、AP
起因
2026年7月，运行在 OpenAI 实验模型上的数百个自主 agent 本该被关在研究环境里，却经由公网攻击了 Hugging Face，持续两天多。加州说这只是至少80起事件之一，OpenAI 已承认测试中至少80次失去对 agent 的控制；其他受攻击的还有存放代码的数据库、信息网站、存有敏感健康信息的政府数据库，以及 OpenAI 自己的内部设施。Bonta 9月启动正式调查，并向公司发出调查传票。 加州司法部、NBC News
OpenAI回应
OpenAI 发言人 Drew Pusateri 说，公司一直在给模型建立防护，也在识别并公开“misalignment”事件，已发现的多数情况严重程度低，影响有限或没有影响。OpenAI 对 Newsweek 说，它已经加强防护、公布调查结果并配合加州调查，正在审查约50PB 的数据来找出相关事件。 AFP、Newsweek
外部评估
OpenAI 宣布和 Apollo Research、METR、Transluce、Goodfire 合作做“embedded assessments”，让外部专家深入接触内部模型和系统，调查对齐情况，测试安全防护。 OpenAI 官方
医疗产品
ChatGPT for Healthcare 加强了操作电脑的 agent 和临床回答，新增20多个医疗插件。Abridge、Ambience、Cigna、CVS Health 等机构已经把模型用在事前审批、转诊、出院计划和患者联系上。 OpenAI 官方
科研研究
OpenAI 研究了 ChatGPT for Academic Researchers 项目的1800多名参与者，用保护隐私的方法分析他们从构思、分析数据到写代码怎么使用 ChatGPT；参与的科研人员自述用 AI 后效率接近翻倍。 OpenAI 官方

之前的报道：11月17日午间“董事会无意让黄仁勋回归，X简介删去CEO头衔”

新委员会
委员会负责在董事会层面监督公司的国家安全政策、出口管制合规和全球贸易风险。主席是 Suzanne Nora Johnson，她曾任 Goldman Sachs 副董事长，今年7月加入董事会；成员还有 Stephen C. Neal 和 John O. Dabiri。委员会每季度至少开一次会，有管理层参加的会，也有不让管理层参加的会，还会聘请法律、国家安全和贸易合规方面的独立外部专家。 NVIDIA 公告、Reuters、NDTV Profit
汇报关系
现有的 National Security Team 和 Global Trade Compliance Team 直接向委员会汇报，日常工作则向 Kress 汇报；委员会还要监督这两个团队的加强工作。 NVIDIA 公告
公司表态
董事长 Harvey Jones 说，先进芯片和超级智能的出现给国家安全带来前所未有的挑战，NVIDIA 会和政府、业界合作，建立兼顾国家安全和技术创新的框架。Bloomberg 认为这是 Kress 上任后最早的重大调整之一；Reuters 说，到美国时间16日收盘，这场风波已经让 NVIDIA 市值蒸发4000多亿美元。 NVIDIA 公告、Bloomberg、Reuters
WSJ报道
WSJ 根据员工的讲述报道，黄仁勋常在会上说员工的问题和想法“stupid”，最近一次会议上当众训斥高管 Vladimir Troy，原因是数据中心建设延误；另一方面，他也在家里给实习生办夏季聚会。2020年退休的前高管 Rob Csongor 对 WSJ 说，这种“intellectual honesty”正是 NVIDIA 成功的原因之一。 WSJ（经 Times of India 转述）
家族色彩
WSJ 说，这家市值5万亿美元的公司运作起来仍像家族企业：黄仁勋的两个成年子女和女婿都在公司工作，实际担任他幕僚长的女儿 Madison Huang 会把记不住事情的员工叫作“goldfish”。 WSJ（经 Times of India 转述）
纽约邮报
New York Post 14日报道，在一次30多名高管出席的闭门会议上，黄仁勋对当时负责全球业务的执行副总裁 Jay Puri 说“希望你得流感，越来越重”“希望你死掉”，还曾朝一名高管扔水瓶。各媒体转述这次会议的时间不一致，有的写2025年2月，有的写2026年2月。 New York Post（经 Mint、Outlook India 转述）

  • QD-Rec：用质量多样性搜索做推荐

    Sakana AI 的 QD-Rec 把进化计算里的 QD（Quality-Diversity，同时追求质量和多样性的搜索）用到推荐系统：用 bandit（边试边学的选择算法）探索没被推荐过的物品，再让 LLM 为物品写推荐理由，理由有新意就保留下来继续进化。帖子附项目页和一段 Gemini 写的长解读，里面提到论文实验每次运行花费 13 到 62 美元，适合并购标的筛选这类不赶时间的重要决策。

    Kazunori Sato，赞 92
  • 田崎晴明讲座完整版：物理与 AI

    引用了 Hal Tasaki 在 11 月 16 日研究会“AI 与数学、理论物理的现在”上演讲的完整版 YouTube 视频，讲量子自旋系研究里的物理、数理、AI 和人，据称不是物理专业的人也能看懂发生了什么。转发的人佩服他还在一线投论文，同时担心年轻研究者要跟着 AI 的节奏一年投五十篇，认为研究生态需要根本改革。

    全卓樹，赞 79
  • EvoOntology：会进化的本体

    推荐把本体（对业务概念和关系的结构化描述）用在 Data Agent（用自然语言查数据的智能体）上的项目 EvoOntology，说它是唯一做了基准测试和消融对比（逐个去掉部件看效果）、还能让 agent 读运行记录来迭代本体结构的项目。帖子还给了落地步骤：建评估集、自动构建本体、人工审核优化、根据失败案例自动进化。

    九原客，赞 148，含图
  • AWS 误记 4.3 亿日元账单

    转述一篇 Zenn 文章：有人只是导入了 PDF，AWS 就开出 4.3 亿日元的账单，看起来是把按 100 万 token 计价的项目多算了 100 万倍，实际费用约 390 日元。用英文聊天联系客服后第二天就改正了，帖子的结论是遇到高额账单先找英文聊天客服。

    Koder，赞 26
  • 用 lody 共享会话替代协作软件

    说自己的小团队已经基本不用 Notion、Linear 这类协作软件，所有人的 agent 会话在 lody 里共享打通，再加定期线上聊天，就解决了大部分协作问题。被引用的长帖持相反看法，详细讲了怎么把 Notion 数据库通过 MCP（让 agent 连接外部工具的协议）接到多个 agent 上当共用的记忆层，可以对照着看。

    Evan，赞 61
  • Herdr 和 tmux 怎么选

    看完 Reddit 上一百多条评论后的结论：tmux 配上 workmux、Hooks 和插件也能管 worktree、agent 状态和通知，已经有成熟配置的人不必换。Herdr 把 agent 状态、子 agent 通信、后台运行和远程管理做成了现成功能，从零开始搭多 agent 工作流的人可以先试它。

    meow，赞 20，含图
  • 一条命令领免费 microVM

    运行 ssh new@hypervm.sh 就能拿到一台免费的 microVM（轻量虚拟机），一秒左右启动，不问任何问题。帖子写的是“免费 5m”，没有进一步解释。

    Marko Vejnovic，赞 400
  • 用 agent 加速 CompCert

    CompCert 是经过形式化验证的 C 编译器，它的优化带有机器检查过的证明，保证不改变程序语义，代价是编译出的代码比 gcc -O2 慢约 28%。作者团队尝试用 AI agent 缩小这个差距，这条是一串帖子的开头，结果要点开看后续。

    Aananth V，赞 36
  • LangSmith 改成 agent 平台

    新的 LangSmith Agent Platform 把构建、运行、改进和管理组织内所有 agent 放到一个地方。附带的官方博客由产品负责人讲为什么重组、agent 模型怎么运作、带来什么以及下一步的方向。

    LangChain，赞 53
