Hysteria贡献者haruue被判刑三年半

3 条帖子，合计浏览 11.8 万次

开源翻墙代理软件 Hysteria 的贡献者 haruue 被中国当局以“破坏计算机信息系统罪”判处3年6个月有期徒刑，X 上转述的项目公告说他只是外部贡献者，开源代码本身并不违法。中文圈另有帖子说，还有多名给 Hysteria 写过代码的开发者被抓，一位做翻墙软件的从业者自述朋友被当作诱捕他的人质。只是给开源项目提交代码也可能被追究，这是讨论的焦点。以下经过来自 X 上的帖子，没有找到媒体报道。

判了多久
haruue 2025年12月被江西赣州的国家安全机关抓走，罪名是“破坏计算机信息系统罪”。2026年10月他被判有期徒刑3年6个月。 X 用户
项目说法
Hysteria 说 haruue 只是向项目提交过代码的外部贡献者，不掌握项目的任何控制权。项目称自己是兴趣驱动的公益开源项目，开源代码不违反包括中国在内任何国家的法律。 X 用户
不止一人
翻墙软件从业者甘文11月25日在 X 上说，多名给 Hysteria 写过代码的开发者被抓，至今仍被关押。他还说防火墙封锁变严以后，一些翻墙服务商已经开始弃用 Hysteria。 X 用户
项目概况
Hysteria 用 Go 语言写成，基于 QUIC（一种跑在 UDP 上的传输协议），采用 MIT 开源许可，GitHub 上约2.3万星。haruue 在仓库贡献者列表里排第二位。 GitHub

补充来源：GitHub - HyNetworks/hysteria
