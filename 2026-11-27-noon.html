Nadella：Claude Code让IDE半年内失色

6 条帖子，合计浏览 5.2 万次

微软 CEO Satya Nadella 在科技通讯 The Pragmatic Engineer 的播客里承认，Anthropic（开发 Claude 的 AI 公司）的命令行编程工具 Claude Code 让微软措手不及，IDE（集成开发环境，例如 VS Code）大约半年就“淡出”了，一个泰国科技网站转述了这段话。时间线上的开发者也在交流怎样围绕 AI 智能体重新安排 CI（持续集成）、代码审查和团队分工，这些做法来自个人账号。

他的说法
Nadella 对主持人 Gergely Orosz 说，Anthropic 的模型让命令行真正成了一种独立的编程形态，微软手握 GitHub Copilot 和 VS Code，却没有现成的应对。他也说这未必是永久的转变，IDE 可能会换一种形式回来。 The Next Web、it-daily
协议由来
一位中文用户指出，编辑器接入智能体的开放协议 ACP 是编辑器 Zed 提出的，第一个接入的是 Google 的 Gemini CLI。Zed 发布那篇博客6天后，Claude Code 也接入了 ACP。 X 用户
云端运行
云端机器服务 Boxd.sh 推出 Agents API，可以用代码在它的云端机器上运行 Claude Code、Codex 或 Antigravity，做后台智能体，还能横向扩到几千个互相分派任务的智能体。转发的用户觉得这比在家里放一台 Mac mini 跑更靠谱。 Boxd.sh 官方、X 用户
夜间构建
一位中文开发者说，他正把项目的 CI 改成每个 PR（提交给别人审核的代码修改）和每次提交只跑轻量的编译和代码检查，重的集成测试放到每晚统一跑。另有一个独立的智能体循环负责持续集成和修复。 X 用户
审查流程
另一位用户说，多智能体协作只有在每个智能体都留下可检查的产物时才有用。他的代码审查流程是一个智能体提方案，一个核对，一个汇总改动，最后由他自己拍板。 X 用户

Hysteria贡献者在中国被判三年半

3 条帖子，合计浏览 11.8 万次

开源翻墙代理工具 Hysteria 发布公告说，外部贡献者 haruue 因为给项目提交过代码，2025年12月被江西赣州的国家安全机关以“破坏计算机信息系统罪”抓走，今年10月被判有期徒刑三年六个月。中文技术圈的几个账号转发了这份公告，还有人说被抓的不止一人。以上消息来自项目公告和个人账号的转述，没有找到媒体报道。

公告内容
Hysteria 说 haruue 只是外部贡献者，不掌握项目的任何控制权。项目称自己是兴趣驱动的公益开源项目，开源代码没有违反包括中国在内任何国家的法律。 X 用户
不止一人
一个中文时事账号转述翻墙软件从业者甘文11月25日的帖子说，多名给 Hysteria 写过代码的开发者被中国当局抓捕，至今仍被关押。甘文还说，防火墙封锁更严以后，一些翻墙服务商已经开始弃用 Hysteria。 X 用户
当事经历
开发者 Wencey Wang 引用这条消息说，今年早些时候他也遇到过类似的事：他最好的朋友被秘密警察扣作人质，被要求打电话假装邀请他回深圳吃饭，好趁机抓他。 X 用户
项目背景
Hysteria 是基于改造过的 QUIC（一种基于 UDP 的传输协议）的代理工具，把流量伪装成普通的 HTTP/3 来对抗审查。haruue 列在项目 GitHub 页面贡献者名单的前列。 Hysteria GitHub

Switch 2自制工具NUPlay可从SD卡直接跑游戏后续

5 条帖子，合计浏览 7,737 次

之前的报道：11月26日晚间“nx2-relink让Switch 2备份当自制程序跑”

Switch 2 破解圈又多了一个不用电脑的办法：一位开发者发布 NUPlay，在装了 kaiHEN（让 Switch 2 运行自制程序的工具）的机器上，把 .nup 格式的游戏包放进 SD 卡就能直接启动。一位用户说，朋友已经用它从 SD 卡跑起 Switch 2 游戏的拷贝。时间线上也有人在 Wii U、红白机和超任上折腾自制软件，以下进展都来自个人账号。

怎么用
把 .nup 文件放进 SD 卡的 /switch/GAMES 文件夹，在菜单里选中游戏按 A 就能启动，加载器直接从包里读程序和游戏文件，不用再给每款游戏单独做移植。转述的用户说还要清理一些东西，但确实能跑。 X 用户
游戏包
GitHub 上的 KaiDump 是给装了 kaiHEN 的 Switch 2 用的游戏导出工具，能把游戏本体、更新和 DLC（追加内容）导出成 NUP 包等格式，存到 SD 卡或电脑。作者说它只读取游戏内容，不改动游戏和系统存储，项目还在实验阶段。 KaiDump GitHub
手柄模拟
