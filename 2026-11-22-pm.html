日商称社保费约占报酬三成，要求按实发工资计费

1 条帖子，合计浏览 10.3 万次

日本商工会议所（日商，全国中小企业组成的经济团体）和东京商工会议所19日发表社会保障改革意见书，称在职者和中小企业负担的社会保险费已经占到总报酬的约三成，“已经到了极限”。意见书要求改掉按工资档位计算保费的规则，因为现行规则下涨了工资，到手收入也可能反而减少。法律新闻网站弁護士JPニュース报道了这件事，转发报道、主张把社保费减半的帖子获得5000多个赞。

负担变化
中小企业员工参加的协会けんぽ（健康保险），平均费率今年4月从10%降到9.9%，是34年来第一次下调。同一年度开始征收的“儿童育儿支援金”约相当于年收入的0.23%，把降幅抵消了。 弁護士JP新闻
计算方式
现在的保费按“标准报酬月额”计算，也就是把工资套进一定幅度的档位。意见书称这是手算时代的遗留，要求改成按每月实际发放的工资直接乘以费率。 弁護士JP新闻
双重负担
中小企业要和员工分摊育儿支援金，还要另外缴纳“儿童育儿拠出金”（企业为育儿政策缴的钱）。日商称这对中小企业是双重负担，要求重新设计。 弁護士JP新闻
老人负担
意见书主张按收入和资产等负担能力分担医疗费，年龄不再作为标准。它还要求政府在2026年度内对扩大介护保险两成自付的范围作出结论，这件事原定2024年度前定下，一直被推迟。 弁護士JP新闻
下一步
意见书会提交给政府相关部门。政府正在加快讨论老人看病自付比例和社保改革的时间表。 弁護士JP新闻

OpenAI开放ChatGPT登录，本地应用可用订阅额度

2 条帖子，合计浏览 4.0 万次

OpenAI 在 GitHub 公开了“Sign in with ChatGPT”开发工具包。开源、在用户自己电脑上运行的应用接入后，用户可以用 ChatGPT 账号登录，并在授权后用自己的 ChatGPT 订阅额度驱动应用里的 AI 功能，开发者不用另外申请 API 密钥（调用接口的凭证）。中文圈的开发者认为这对开源 AI 智能体是好消息，两条介绍帖合计获得近400个赞。

怎么用
用户在应用里用 ChatGPT 账号登录。用户同意后，符合条件的用户可以拿自己的 ChatGPT 方案驱动应用的 AI 功能，不用设置 API 密钥。 OpenAI GitHub
适用范围
这个工具包面向在用户本机运行的开源应用。OpenAI 写的代码和文档采用非商业许可证。 OpenAI GitHub
包含什么
里面有本地 Node.js 开发包、React 界面组件、登录按钮和图标等设计素材。还附带一个 macOS 示例应用 Paste Perfect，能把复制的文字改写后粘贴到别的应用里。 OpenAI GitHub
运行条件
示例应用需要 macOS 14 以上、Node.js 22.12 以上，还要装 Xcode 命令行工具。 OpenAI GitHub

Inkling 2 Mini公布成绩，同级开源多项第一后续

5 条帖子，合计浏览 427 万次

之前的报道：11月21日早间“Thinking Machines发布笔记本可跑的小模型”

AI 初创公司 Thinking Machines 公开了小模型 Inkling 2 Mini 的详细评测：在总参数1000亿以下的开放权重模型里，它在多项编程智能体测试中排第一。公司还同时放出一个可以调整循环次数的研究版模型，用来研究循环结构对监督模型的影响。官方发布帖获得1.9万个赞，时间线上有开发者晒出在旧显卡上跑它的速度。

此前
Inkling 2 Mini 总参数约264亿，内存占用约20GB，中间几层对每个词元重复运行三次。 Thinking Machines 官方
成绩
它在编程智能体测试 DeepSWE 上得48.2%，是1000亿参数以下开放权重模型里最高的。在第三方 Artificial Analysis 综合指数上得20.1分，和 Qwen3.8-27B 并列。 Thinking Machines 官方
弱项
多轮对话和带很多约束的指令不如 Qwen3.8-27B。官方说循环不会让模型记住更多知识，知识类测试和同尺寸模型差不多，要靠搜索和工具补。 Thinking Machines 官方
研究版
研究版模型循环1次时，不写思维链能完成的任务长度约16秒，循环3次增加到约37秒。循环越多思维链越短，但仍然读得懂，官方说这关系到能不能靠读思维链来监督模型。 Thinking Machines 官方
能效
斯坦福的团队在 NVIDIA DGX Spark 上测“每焦耳能换来多少智能”，它得0.703，Qwen3.6-35B-A3B 是0.430。 Thinking Machines 官方
