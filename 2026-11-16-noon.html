NTT Docomo 全国 5G SA 用户通话和上网困难

3 条帖子，合计浏览 236 万次

NTT Docomo 说，11月16日上午10点02分左右起，全国签约 5G SA 服务的用户打电话、上网和收发短信都有困难。到上午11点30分的第三次通报时故障还没解决，原因还在调查，恢复时间没有公布。这是 Docomo 本月第三次出现 5G SA 故障。

影响范围
影响全国签约 5G SA（只用 5G 专用设备通信的选购服务）的用户，语音通话、数据通信和 SMS 都难以使用。使用 Docomo 线路的 MVNO、5G SA 签约用户以外的 5G 和 4G 用户不受影响，110、119 等紧急通报也不受影响。 NTT Docomo 官方、共同社
临时办法
Docomo 建议在手机的网络设置里选择 4G，再重启手机或开关一次飞行模式，这样有可能恢复使用。 NTT Docomo 官方、ITmedia
目前状态
截至上午11点30分的第三次通报，故障仍在持续，原因正在调查，恢复时间将另行通知。Docomo 说还没有发现非法访问，并否认是网络攻击造成的。 共同社、读卖新闻、Buzzap
本月故障
11月5日和11日也发生过全国性的 5G SA 故障。5日最多约158万7000条线路受影响，持续约14小时；11日从10点34分持续到19点17分，约8小时43分。两次的原因都是收容 5G SA 用户的交换机拥塞。 ITmedia、共同社

朝日：短期转卖拟增设1至3年税档，12月写入大纲后续

15 条帖子，合计浏览 8.6 万次

之前的报道：11月16日早间“梅田塔楼顶层降价1.5亿，中野新盘推迟到1月”

朝日新闻报道，政府和执政党在研究对短期转卖公寓加税，方案包括给1到3年内卖出的设更高的税率，准备写进12月的2027年度税制改正大纲。时间线上列出的降价房源和成交情况都是个人账号的观察，没有官方统计。

课税方案
现在个人卖房获利，持有5年以下的所得税加住民税约40%，5年以上约20%。正在研究的方案是把5年以下再细分，例如增设1到3年以内的档位，越早卖出税率越高；增税对象包括所得税和不动产取得税。 朝日新闻
其他方案
另一个方案是部分启用一项为抑制土地投机设立、1998年泡沫破裂后停用至今的土地转让所得加重课税制度；还有方案是新建公寓短期内转卖的，不再享受不动产取得税的减轻措施。因调职等原因很快卖掉自住房的情况也有，怎样把投机和实际居住需求区分开是难点。 朝日新闻
时间表
政府和执政党打算把这些措施写进12月汇总的2027年度税制改正大纲，具体制度还要细化。自民党政调会长小林14日说，子育世代买不起自住公寓是个问题，会在税调和党的调查会上“好好拿出结论”。 朝日新闻、ANN
各方担忧
产经新闻报道，有声音担心规制过度可能引发房价急跌。 产经新闻
房源降价
有用户说，パークコート文京小石川ザタワー一户降价2000万日元，降幅8.4%。另一位用户列出近来因便宜引起关注的房源：シティタワーズ豊洲ザツイン 85㎡、シティタワー有明 70㎡、大崎ウェストシティタワーズWEST 55㎡。 X 用户
买气
有用户统计三井のリハウス上标着“已有购买申请”的房源：千代田区为0，中央区300套里有2套，港区300套里为0。另一个房产账号转述都内业者的说法：负债和库存多的企业优先卖房，金融机构收紧融资，买方购买力下降；业者预计明年起售价会慢慢往下走，不太会急跌。 X 用户

模型规格
Qwen4-Max 采用新的 MoE（混合专家）架构，参数2.4万亿，可以输入文本、图片和视频，输出文本，上下文窗口100万 token，主打编程、办公和长时间运行的 agent 任务。 Qwen 官方、Tech in Asia、Unite.AI
价格
国际站每百万 token 输入1.5美元、输出4.5美元、隐式缓存命中0.075美元；国内是输入10元、输出30元、缓存0.5元。新加坡区上一代 Qwen3.8-Max 是输入2美元、输出6美元，这次两项都降了25%；新加坡区另有100万 token 的免费额度，有效期90天。 AIbase、Unite.AI
官方评测
阿里自己的 Work360 专业任务评测，得分从 Qwen3.8-Max 的47.74升到52.69，单个任务平均成本从4.43美元降到1.67美元，降了六成多。Terminal-Bench 4.0 在同样的 Xhigh 档位下，每次尝试平均用 token 从28.9万降到15.1万，少了近一半，得分从37.9升到48.5。 Qwen 官方、AIbase
第三方排名
Arena.ai 的 Agent Arena 上，Qwen4-Max 总排名第14（上一代第39），在1.47万次真实 agent 会话中净提升7.5%，是排名最高的中国模型；阿里因此成为排名第一的中国实验室、总排名第5，前面是 Anthropic、Google、OpenAI 和 Meta。Code Arena 的 WebDev 榜上，它以1750分（初步）排第6，比 Qwen3.8-Max 的1676分高74分；HTML 1748分排第6，Brand & Marketing 1705分、Reference-Based Design 1770分都排第8。 Arena.ai
上线渠道
除了 QwenCloud 的 API，还可以在千问 AI 平台、千问 Office、Qoder 等应用里使用；OpenRouter 和 OpenCode Go 也已接入。 Tech in Asia、OpenRouter、OpenCode

7至9月实际GDP年率减0.1%，四季度来首次负增长

5 条帖子，合计浏览 12.0 万次

内阁府16日公布7至9月 GDP 速报：实际 GDP 环比减0.02%，按年率计算减0.1%，是四个季度以来第一次负增长，比市场预期的增长差。主要原因是个人消费连续两个季度下降。

主要数字
扣除物价因素的实际 GDP 环比减0.02%，年率减0.1%；名义 GDP 环比增0.4%，年率增1.6%。时事通信调查的21家智库预测中值是年率增0.3%，路透汇总的预测中值也是年率增0.3%。 时事通信、路透
个人消费
个人消费环比减0.3%，连续两个季度负增长。上一季度在涨价前和明年4月节能标准收紧前抢购的空调、汽车出现回落，牙刷、衣服、大米、点心、海鲜的支出也减少了。原油涨价推高包装成本，9月食品集中涨价；台风、暴雨和低温又让外出和住宿减少。 共同社、时事通信、TBS
设备投资
企业设备投资增1.6%，三个季度来首次转正，主要靠半导体制造设备和电子计算机，背后是 AI 和数字相关需求。 共同社、时事通信
进出口
出口减0.2%，主要是研发服务不振；进口增2.5%，主要是采购美国原油增加。进口增加会拉低 GDP。 共同社
市场反应
数据公布后日经平均指数开盘跌700多点，午盘一度跌超1000日元，彭博认为对 NVIDIA 的担忧也是原因；日元汇率在1美元兑159.75日元左右。 Bloomberg、BigGo

日银审议委员高田：进入加快逼近中性利率的新阶段

3 条帖子，合计浏览 3.6 万次

日银审议委员高田创16日在德岛市演讲，说已经进入不拘泥于节奏和幅度、灵活加息、加快向中性利率靠拢的新阶段。

讲话内容
高田说，现在是不拘泥于加息节奏和幅度、灵活加息的阶段，已经进入加快向中性利率（对经济既不刺激也不抑制的利率水平）靠拢的新阶段；他把2026年称为需要灵活加息的“体制转换”（レジーム転換）。他还说，在金融环境回到正常的过程中，加息和降息都要灵活应对。 Bloomberg、みんなのFX
物价判断
他说海外央行也在加息，中东局势推高物价，物价有上行风险，物价上涨的二次影响也更容易出现；同时 AI 投资基本保持坚挺。 Bloomberg、みんなのFX
此前立场
高田上个月提议把利率提高到1.5%，没有获得通过。他认为在截至2027年3月的本财年后半段，通胀可能超过日银2%的目标，日银应当停止推高基础通胀的姿态，向市场表明防止物价向上偏离的决心。 Arab News Japan
委员分歧
同为审议委员的浅田统一郎12日演讲时说，眼下实体经济未必强劲，今后的加息节奏需要充分留意，态度比高田谨慎。 日刊现代

    把 skills、提示词、规则等能力文件只放在 ~/.agents/skills，其他地方用软链接指过去；会话历史和缓存放进单独目录，用 Mutagen 双向同步；token 和登录凭证每台机器各自登录，写进 .gitignore 和同步工具的忽略列表，绝不同步。帖子说同步凭证会让另一台机器的 token 失效，表现为反复要求重新登录，附有具体命令可以照着做。

    linyun，赞 9，含图
  • CubePod 沙箱的五个设计目标

    介绍自研 agent 沙箱 CubePod 的设计：停机即删除 Pod、约1秒跨节点挂载唤醒，系统盘和 /workspace 分开持久化，基于 SPDK 和 NVMe-oF 块设备并用写时复制（只复制改动部分）做秒级克隆，用 Kata Containers 轻量虚拟机隔离并限制出网，兼容 E2B SDK 和 MCP。帖子说已在 CubePlex 里用它替换 OpenSandbox，写前端代码的速度接近本地。

    chris，赞 6
  • YC 里扎堆的 agent 沙箱产品清单

    列出 Agent 37、Boat、Superserve、Maritime、Orgo、Boxes.dev、machine0、InstaBox 等给 agent 用的云端沙箱，每个用一句话说明特点，例如带桌面和快照的常驻 Ubuntu 虚拟机、可连同内存暂停恢复的 Firecracker 轻量虚拟机、按分钟计费的 GPU 虚拟机。可以拿来挑选让 coding agent 在云端跑任务的环境。

    Kalan，赞 27
  • loopx：长程 agent 开源框架

    推荐开源项目 loopx，称它是做长时间运行 agent 最好用的 harness（包在模型外面、负责调用工具和推进流程的框架），装上就能用。帖子附了项目讲上下文传递的中文博客。

    Tommy Xiao，赞 20
  • Yosei：手机遥控无屏 Mac

    Yosei 可以从 iPhone 或 iPad 远程操作没接显示器的 Mac，支持最高120 FPS 画面、触控手势、Apple Pencil、双向音频和剪贴板，可通过 USB-C、Wi-Fi 或 Tailscale 连接。它还能让 Claude Code 等 agent 通过 MCP 操作 Mac，点一下屏幕就能收回控制权，目前免费公测。

    Techjunkie Aman，赞 95，含图

    Greg Brockman，赞 1,286
  • 未婚情侣对半名义买房的赠与税

    举例说明：6000万日元的公寓名义各占一半，1000万首付全由男方出，女方持分里的500万会被视为男方赠与，按（500万减110万）乘20%再减25万计算，要交约53万日元赠与税，入籍后也一样。避免的方法是让名义比例和实际出资比例一致。

    ミゲル，赞 31
