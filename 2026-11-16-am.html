11月15日投票的福冈市长选举有13人参选，得票最多的稻富修二也没拿到有效票的四分之一，按公职选举法要重新选举。16日的选举会将正式确定，重选日期初步定在明年1月3日公告、1月17日投票开票。

计票结果
有效票59万2723张，当选至少要四分之一。得票依次是：稻富修二13万7667票，新村优9万3824票，森健太郎9万3206票，调崇史7万1964票，神野元基4万8195票，吉富景子4万6156票，其余7人各不到3.4万票。稻富离当选还差约1万500票；投票率45.58%，比4年前高11.27个百分点。 TNC、TBS
原因
做了4届16年的市长高岛宗一郎8月23日在社交媒体上宣布不再参选，也没有指定接班人，之后元众院议员、3名前市议员、医生、校长等人相继参选，人数是政令市首长选举最多的一次。主要政党多数让支持者自由投票，又没有明确的争议焦点，票就分散了。 读卖新闻、Daily Sports、mediadogs
重选日程
重选要先经过原则上2周的异议期，之后50天内举行；11月30日前没人提出异议的话，要在明年1月19日前投票，相关人士说1月3日公告、1月17日投票开票是主要方案。高岛的任期到12月6日为止，按日程会出现一段没有市长的时期。 读卖新闻、TNC
重选规则
重选从报名参选开始重来，参选人数不受限制，这次13人以外的人也能参选；如果再次有很多人参选，还可能要“再再选举”。总务省说，首长选举重选全国有7例，包括札幌市和东京品川区；政令市是继2003年札幌之后的第二例。 读卖新闻、Daily Sports
费用人力
福冈市选举管理委员会说，这次选举花了8亿3000万日元，重选费用会随候选人数增减；投票所有239个，重选的投票事务要延人次3600人，开票要700人。 X 用户引用西日本新闻
候选表态

结婚育儿赠与免税明年3月废止，丸龟率先降价后续

5 条帖子，合计浏览 16.7 万次

之前的报道：11月13日早间“政府与执政党拟废止结婚育儿赠与免税等三项优惠”

要废除的结婚育儿资金一次性赠与免税制度，原定适用期限是2027年3月31日，金融厅等已要求到期废止。另一方面，为应对明年4月起的食品消费税减税，丸龟制面11月25日起把主力乌冬面降价最多约11%。

废除对象
这项制度依据租税特别措置法第70条之2之3：父母、祖父母通过金融机构签管理合同，一次性给18岁以上、不满50岁的子孙结婚育儿资金，每人最多1000万日元免缴赠与税，其中结婚费用最多300万日元，受赠人有收入要求，适用期是2015年4月1日到2027年3月31日。金融厅和こども家庭庁要求到期废除；据税理士解说，金融厅的要求里也包括期限前已经存入的资金继续免税。 税理士解说
相关制度
类似的教育资金一次性赠与免税（最多1500万日元）已经在2026年3月31日到期结束；每年110万日元以内的赠与，以及需要时随时支付的生活费、教育费，仍然免税。 税理士解说、GMO クリック証券
改革背景
政府和执政党要在2027年度税制改正中废除3项税收优惠，这次主要审查2026年度末到期的121项；高市政权打着“日本版 DOGE”的旗号，重新检查效果不明显的减税和补贴。存废由执政党税制调查会年底前正式决定。日经另有分析文章，标题是“民粹主义的结果，首次下调消费税，与政局和市场混乱相伴”。 日经
丸龟降价
丸龟制面11月25日起把5款主力乌冬面的并盛降价50到60日元：かけうどん从440日元降到390日元，釜玉うどん从550日元降到490日元，明太釜玉うどん和きつねうどん从640日元降到590日元，焼きたて肉うどん（かけ）从890日元降到840日元，小份不降价。这是2000年创业以来第一次给主力商品降价，分量和用料不变；社长山口宽说，减税后在超市买食品的人会变多，公司有危机感。 读卖新闻、共同社、TBS

magpie 以封号风险为由下线 Antigravity 接入

5 条帖子，合计浏览 7.8 万次

AI 路由工具 magpie 从 v0.1.4232 起下线内置的 Antigravity 接入和官方插件，理由是这种方式容易被封号，并推荐改用调用本机 agy CLI 的社区插件。Google 官方的说明更严格：个人方案下，让第三方 agent 包装、调用 agy 都不允许。

下线内容
magpie 内置的 Antigravity 接入和官方插件 opencode-antigravity-auth 都已下线。magpie 说它们模拟客户端直连 Google 接口，账号容易被封，现在 magpie 不再用这种方式向 Google 发任何请求。 magpie 官方
替代方案
magpie 推荐改装社区插件“Antigravity (local agy CLI)”，通过 ACP 驱动用户本机已登录的 agy CLI，由官方客户端自己发请求；magpie 说这样风险更低但不是零，提醒不要多个账号同时高频运行。安装方式是在 Plugins 页搜 agy，或运行 magpie plugin add @magpie-community/opencode-agy-cli-auth。 magpie 官方
官方规定
Antigravity 追加条款第6条规定，通过第三方软件、工具或服务访问服务属于违约。Google 论坛工作人员说，条款9月后没改，官方 FAQ 在2026年10月中旬新增说明：Free、Plus、Pro、Ultra 等个人方案下，不支持把 agy 包进第三方编程 agent 或应用，也不支持自动轮换账号；工作人员点名 Claude Code、OpenCode、OpenClaw、T3 Code 等，说用 Antigravity 登录配合这些工具会被停用或终止账号。 Google AI 开发者论坛
封号案例
一位 Google AI Ultra 订阅用户在论坛上说，美国时间11月12日他的 Antigravity CLI 被停用（403 PERMISSION_DENIED），原因是他的 Claude Code 在本地脚本里以无头模式（-p）并行运行 agy 审查代码。另有用户说，用 OAuth 把 OpenCode 接到 Code Assist 后账号被停，撤销授权并申诉后一周仍未恢复。 Google AI 开发者论坛
申诉方式
Google 工作人员说，论坛上不能人工审核或撤销违反条款的停用，个人账号要登录受影响的 Google 账号，填写针对 Antigravity、Gemini CLI 和 Gemini Code Assist 的申诉表，只交一次；自动处理约需48到72小时，不会发确认邮件，通过后再登录就会自动恢复，重新登录前要先去掉第三方包装工具。 Google AI 开发者论坛
